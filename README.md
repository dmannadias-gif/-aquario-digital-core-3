# Missão Aquário Digital

## Protocolo de Versionamento e Gestão de Ecossistema

Projeto desenvolvido para praticar o fluxo de desenvolvimento corporativo com Git, simulando o gerenciamento de um ecossistema de aquário digital.

## Camadas do Ambiente

- **develop**: ambiente de desenvolvimento, onde as features são integradas antes da homologação.
- **stage**: ambiente de testes/homologação, onde as mudanças são validadas antes de ir para produção.
- **main**: ambiente de produção, contendo apenas o código validado e estável.
